Cisco IOS Configuration Reference

Beginner-friendly Cisco Packet Tracer CLI commands for routers, switches, VLANs, DHCP, and security.

1. Core Router (Router-on-a-Stick & DHCP Setup) 

enable
configure terminal
hostname Core-Router

! Enable GigabitEthernet 0/0 subinterfaces for Inter-VLAN Routing
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 description Admin VLAN

interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 description CS Dept VLAN

interface GigabitEthernet0/0.30
 encapsulation dot1Q 30
 ip address 192.168.30.1 255.255.255.0
 description Cyber Security VLAN

interface GigabitEthernet0/0.60
 encapsulation dot1Q 60
 ip address 192.168.60.1 255.255.255.0
 description Server Room VLAN

no shutdown

! DHCP Server Configuration
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp pool ADMIN_POOL
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 192.168.60.20

ip dhcp pool CS_POOL
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 192.168.60.20
exit

2. Layer 2 Switch Configuration (VLANs & Trunks) 

enable
configure terminal
hostname SW-Admin

! Create VLANs
vlan 10
 name Admin
vlan 20
 name Computer_Science
vlan 30
 name Cyber_Security
vlan 60
 name Servers

! Configure Trunk Port connecting to Router
interface FastEthernet0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,60

! Configure Access Port for Admin PC
interface FastEthernet0/2
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
exit

Project Documentation & Report

Complete B.Tech PBL Project Report on Campus Area Network Design & Implementation.

1. Abstract

This PBL project presents the comprehensive design, simulation, and deployment of a secure **Campus Area Network (CAN)** using Cisco Packet Tracer. Designed for a modern multi-disciplinary academic institution, the network architecture integrates administrative blocks, computer science and cyber security departments, research labs, libraries, and student Wi-Fi zones into a robust hierarchical topology. Security measures including VLAN segmentation, Inter-VLAN routing, and Access Control Lists (ACLs) are implemented to ensure confidentiality and prevent unauthorized lateral movement across sensitive academic and administrative data stores.

2. Project Objectives

  • Design a scalable hierarchical campus network supporting growth across 8 distinct departments.
  • Implement VLAN segmentation to isolate broadcast domains and mitigate network congestion.
  • Configure Inter-VLAN routing using a Cisco Router-on-a-Stick methodology.
  • Automate IP allocation using built-in Cisco IOS DHCP server pools.
  • Enforce granular network security using Extended Access Control Lists (ACLs) and port security.
  • Develop a professional interactive web dashboard (CampusNet) for network telemetry and visualization.

3. Introduction & Network Architecture

Modern college campuses require high-speed, reliable, and secure communication infrastructures capable of supporting voice, video, and high-throughput research traffic. The proposed topology follows the Cisco Three-Tier Hierarchical Model (Core, Distribution, and Access layers). The Core Layer consists of high-speed Cisco 2911 routers connecting to the ISP Cloud. The Access Layer utilizes Cisco 2960 Layer 2 switches connected to departmental workstations and wireless access points.

4. Hardware & Software Requirements

Simulation Software

  • Cisco Packet Tracer 8.2+
  • Modern Web Browser (Chrome, Firefox, Edge)
  • VS Code with Live Server (for web prototype)

Virtual Network Hardware

  • 1x Cisco 2911 Modular Core Router
  • 4x Cisco 2960-24TT Layer 2 Switches
  • 2x Wireless Access Points (WAP 300N)
  • 26x Endpoints (PCs, Laptops, Printers, Servers)

5. Testing and Results

Thorough validation was conducted using ICMP ping tests and traceroute simulations across VLANs. Results confirmed seamless intra-department communication and authorized server access. Unauthorized attempts by guest Wi-Fi clients to query the server subnet were successfully intercepted and dropped by Extended ACL 100 on the Core Router.

6. Conclusion & Future Enhancements

The Campus Area Network project successfully demonstrates enterprise-grade network design principles. Future enhancements include integrating OSPF dynamic routing, deploying redundant HSRP gateway failover, and connecting real SNMP-enabled hardware telemetry using Python and Prometheus/Grafana.
